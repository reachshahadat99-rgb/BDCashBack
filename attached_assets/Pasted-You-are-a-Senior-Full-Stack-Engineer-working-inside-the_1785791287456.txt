What "Claim" means here

Cashback in this system isn't a manual claim button that credits money on click — it auto-moves from cashback_pending to cashback_released after delivery + the return window, per the existing lifecycle. So "Claim" in the UI means: the user can always see where their cashback stands and there is a clear moment where it becomes available/withdrawable — not a literal "Claim Now" button that bypasses the return-window logic. Do not build a UI that lets a user click something and get cashback released early; that would break the fraud/return-window protection already in the system.

A "See Cashback Details" link/click-through from any product cashback badge to that item's status once purchased (via order detail), so the badge isn't just decorative.
